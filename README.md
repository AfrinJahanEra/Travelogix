# Travelogix - A Smart Travel Companion


## **Overview**

Travelogix is an innovative travel management software designed to cater to three distinct user roles: Travelers, Transport Agencies, and Admins. Built with Java OOP principles, this application ensures secure user authentication with unique email-based login and password hashing. Each user role is provided with a tailored interface to streamline their tasks, enhance their travel experience, and improve operational efficiency.





## **Features**

### **Common Features**

- Secure user authentication system with **unique email identification**.
- **Password hashing/encryption** for enhanced security.
- Role-based dynamic interfaces that adapt to the user’s login.

### **Traveler Features**

- **Itinerary Management** with:
  - Alarm and calendar system.
  - Checklists for items.
- **Trip Planning Tools**:
  - Browse transport options for desired destinations.
- **Travel History**:
  - View past travel records.
- **Note Management**:
  - Add and organize written and voice notes.
- **Budget Cracker:**
  - Plan and manage budgets efficiently with graphical representation .



### **Transport Agency Features**

- Add, remove, or edit transport details.
- View transport details.
- Book available seats for travelers.

### **Admin Features**

- Manage all user login information.
- Approve or reject account deletion requests from transport agencies.
- Oversee system operations and ensure smooth functioning.



## **Installation**

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/AfrinJahanEra/Travelogix.git
   ```

2. **Navigate to the Project Directory**:

   ```bash
   cd Travelogix
   ```

3. **Compile the Project**:

   ```bash
   javac -d bin src/**/*.java
   ```

4. **Run the Application**:

   ```bash
   java -cp bin Main
   ```



## **Usage**

1. **Sign Up/Login**:
   - Use a unique email and secure password to sign up or log in.
2. **Role-Based Interface**:
   - Depending on your role (Traveler, Transport Agency, Admin), the system will guide you to the respective dashboard.
3. **Explore Functionalities**:
   - Travelers can manage their trips and budgets.
   - Transport Agencies can handle transport operations.
   - Admins can monitor and manage system-wide activities.
